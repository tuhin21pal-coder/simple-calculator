# Simple C++ Calculator
<br>
This is a beginner-friendly calculator project I created while learning C++.
<br>
It performs basic arithmetic operations: addition, subtraction, multiplication, and division.
<br>
The program uses a menu-driven interface with switch statements and conditional logic.
<br>
It also handles division by zero and invalid menu choices.
<br>
Concepts practiced: User input, operators, conditionals, and switch-case.
